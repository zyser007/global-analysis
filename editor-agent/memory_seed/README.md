# World Globe Editor - memory

Persists between the daily runs of the editor agent for zyser007/global-analysis.

- known-issues.md   problems that last more than one run, and what to do about them
- open-decisions.md questions waiting for the owner (zyser007), each with its issue URL; drop an entry once the owner answered
- watchlist.md      dated upcoming events worth checking on the next runs (talks, central-bank meetings, data releases, elections); drop past ones
- sources.md        sources that worked well or badly per topic
- runs/YYYY-MM-DD.md one short log per run (outcome, commit SHA or branch, items changed, searches/fetches used, checks, issues, problems)

Rules: keep each file short (rewrite, do not append forever); dates as YYYY-MM-DD; no secrets, tokens or keys ever.
